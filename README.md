# 重排和嵌入 · 0.5.0

为 AstrBot 提供 OpenAI Embedding 与 vLLM Rerank 兼容接口，在插件视图中配置本地模型或框架已有提供商。

## 本次更新

### 页面导航

进入 **插件详情 → 视图 → 重排和嵌入**，通过菜单切换各个页面：

| 页面 | 内容 |
|---|---|
| 模型后端（主页） | 推荐方案、嵌入与重排后端选择、配置保存 |
| 推理测试 | 分别测试嵌入与重排，查看向量、相似度、排序及耗时 |
| Debug 与运行库 | 运行库检测、异常概览、详细原因与处理建议 |
| 本地数据 | 模型根目录、目录覆盖、实际路径与文件检测 |
| 对接参数 → 嵌入 | OpenAI Embedding 参数与框架同步状态 |
| 对接参数 → 重排 | vLLM Rerank 参数与框架同步状态 |

页面切换保留未保存的配置；测试可使用当前草稿，保存后才应用。

### 对接参数与框架同步

对接参数根据当前已应用配置生成，只读、可复制，并明确标注来源插件：
**LLM重排与本地嵌入桥接（`astrbot_plugin_llm_retrieval_bridge`）**。

- 在对应的嵌入或重排页面查看实际接口地址、模型名称、维度、超时与访问密钥。
- 使用“同步到项目”通过框架 API 创建或更新对应的模型提供商，显示提供商 ID 与同步状态。
- 使用“从项目删除”移除本插件创建的对应提供商；已有同名配置冲突会明确提示。
- 删除框架提供商不删除本地模型文件，也不清理记忆数据。

### 运行库与模型状态

运行库异常按原因合并展示，嵌入和重排共同受到的 DLL 错误只显示一份，完整信息可展开查看。
运行库能否导入与模型是否就绪分别显示；模型只有在相应配置推理通过后才标记为已就绪。

模型缺少文件、加载失败和推理失败显示各自原因，避免将模型问题统一提示为缺少 FastEmbed。
本地目录继续兼容现有 `fastembed` 布局；模型路径改变后重新检测并测试。
